## V1 Documentation Rule

V1 is intentionally narrow. The current editor, local persistence, PWA behavior, and portable JavaScript build are V1. Cryptographic identity, authenticated history, memories, relationships, and cross-container transfer are future protocol work and must not be required to use V1.

## Product Principle

**Appearance may be copied. Identity must be proven. History must be earned.**
